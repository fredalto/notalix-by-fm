# Version de parité

Cette version remet volontairement l’interface, les textes, les formulaires, les notes repères, les raccourcis clavier et les variantes d’exercices de la version d’origine.

Corrections déjà intégrées sans modifier l’apparence :

- les niveaux 2 à 4 du violoncelle chargent désormais leurs propres scripts au lieu de ceux de l’alto ;
- les boutons de progression du violoncelle restent dans le parcours violoncelle ;
- la réponse « Ré » est correctement reconnue dans le niveau 4 de l’alto et du violoncelle.

Cette copie constitue la référence de parité pour la suite du nettoyage interne. Une fonction ne doit être centralisée que si les comparaisons visuelles et comportementales restent identiques.
