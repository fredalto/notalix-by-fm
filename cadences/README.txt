CADENCES EXPRESS
================

Ouvrez index.html dans un navigateur récent. Aucun serveur ni accès Internet n'est nécessaire.

Contenu : cadence parfaite, demi-cadence, cadence rompue et cadence plagale.
Le logiciel utilise VexFlow et les échantillons de piano MuseScore 4 issus d'Accords Express.

Fonctions :
- choix direct avec deux cadences minimum ;
- exemples en plusieurs tonalités ;
- quatre accords plaqués avec une fondamentale grave ;
- tutoriel visuel avec les deux accords cadentiels mis en évidence ;
- dix questions équilibrées ;
- correction immédiate et score final.
