# Elements communs

Ce dossier accueille uniquement les elements vraiment partages par plusieurs modules.

- `audio/` : moteur et conventions audio.
- `components/` : composants visuels communs.
- `styles/` : theme et affichage responsive.
- `data/` : donnees et configurations partagees.
- `utils/` : utilitaires techniques sans logique pedagogique.

Les dossiers existants des modules ne doivent pas etre vides ou deplaces ici en une seule operation. Chaque extraction doit etre faite et verifiee module par module.
